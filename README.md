# Pokémon Save Tools for Chinese Handheld Consoles

## About This Project

Many Chinese handheld gaming consoles use emulators or proprietary cores such as `s_g1.so`, which may operate differently from standard Libretro cores. These systems can use RTOS-based firmware, including configurations associated with Little Indian systems and AJ2273S 32-bit processors.

I created this project for a simple reason: I wanted to use my Pokémon save files from RetroArch on my Chinese handheld console and recover my Pokémon without losing my progress.

I'm not a professional programmer or an expert in this field. I developed these tools through research, experimentation, testing and assistance from AI tools such as Gemini and Claude.

The main goal of this project is to help players extract, recover, convert and transfer Pokémon save files between Chinese handheld consoles, RetroArch and other compatible emulators.

## Supported Pokémon Games

The project currently includes tools for:

- Pokémon Ruby
- Pokémon Sapphire
- Pokémon FireRed
- Pokémon LeafGreen

## Save File Operations

The project focuses on working with the save formats used by compatible Chinese handheld consoles and emulators.

Its objectives include:

- Extracting Pokémon save files in SVG format from compatible consoles.
- Converting SVG to SAV and SAV to SVG.
- Recovering Pokémon and progress from existing save files.
- Transferring Pokémon save data to new game files.
- Helping players move their progress between compatible Pokémon game versions and emulators.

**Important:** In this project, SVG refers to the save-file format used by the console, not the SVG vector-graphics format.

## Target Devices and Compatibility

The project is intended for Chinese handheld gaming consoles, including devices such as the SUP M3 and Console X6, as well as other compatible systems using RTOS firmware and the `s_g1.so` emulator/core.

Compatibility depends on the specific hardware, emulator, firmware and save-file implementation. Similar-looking consoles may use different configurations, so each device must be evaluated through actual testing.

## Project Goal

I want this project to help other Pokémon players who own Chinese handheld consoles and want to preserve their Pokémon, recover old progress or transfer their saves to other compatible platforms.

What started as a personal attempt to move my own Pokémon saves between RetroArch and a Chinese handheld console has grown into a collection of tools that I hope will be useful to other players facing the same problem.
